Male changes
------------
- Removed all textures. The material is generated at runtime.
- Reoriented from Z-up to Y-up, centred horizontally, feet placed at y=0 and
  height normalised to 1, so the runtime can work in stature fractions.
- Measured the mesh's half-width and half-depth at 64 height slices. That
  profile is written to src/data/body-profile.json and is what the runtime
  deformation scales relative to.

Rebuild with: node scripts/build-body.mjs <scene.gltf>

Female changes
--------------
- Applied MakeHuman's sparse target deltas as
  final = base + (african female young + asian female young +
  caucasian female young) / 3. Equal weights produce the project's universal
  young-adult female without making one ancestry the unspoken default.
- Applied no muscle, weight, height or proportion extremes; those axes remain
  at the neutral base mesh's default state.
- Retained only the visible "body" face group. Joint and helper face groups
  were omitted, matching MakeHuman's own export masking.
- Converted the generated body-only OBJ to GLB with obj2gltf 3.2.0.
- Removed textures and normalised to Y-up, feet at y=0, height=1 and horizontal
  centre=(0,0), using scripts/build-body.mjs.
- Wrote its independent 64-slice width/depth measurements to
  src/data/body-profile-female.json.

Rebuild:
1. Download the pinned base and three pinned targets above.
2. Run:
   node scripts/apply-makehuman-targets.mjs <base.obj> <female.obj> \
     <african.target>=0.3333333333333333 \
     <asian.target>=0.3333333333333333 \
     <caucasian.target>=0.3333333333333333
3. Run: npx obj2gltf -i <female.obj> -o <female.glb> --binary
4. Run: node scripts/build-body.mjs <female.glb> --name female
